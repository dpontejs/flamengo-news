# Bolão — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** palpite de placar pela cartela 4×4 do pré-jogo e quadro de resultado/ranking no pós-jogo.

**Architecture:** a página (FastAPI + SQLite) guarda jogos, palpites e apelidos e calcula pontos; a
newsletter só registra o jogo, informa o resultado e renderiza. Links pessoais usam o placeholder
`BET_TOKEN_PLACEHOLDER`, trocado por destinatário como o de descadastro.

**Tech Stack:** Python 3.12, FastAPI, SQLite, Jinja2 + premailer, httpx/respx.

**Spec:** `docs/features/bolao.md`

## Global Constraints

- Pontos: exato 5; vencedor + saldo 3 (só vitória/derrota); só resultado 2 (inclui empate com placar errado); erro 0.
- Temporada = ano civil do `kickoff` (fuso `America/Sao_Paulo`); desempate por nº de exatos; empate persistente → título `None`.
- Apelido 3–20 caracteres, único sem diferenciar maiúsculas; o ranking nunca mostra e-mail.
- GET nunca grava; só POST. Só inscritos `active` apostam e aparecem no ranking.
- Prévia e `DRY_RUN` nunca fazem PUT na página. Testes sem internet. Commits `tipo: descrição`, sem trailer.
- Antes de cada commit: `uv run ruff check . && uv run ruff format --check . && uv run pytest`.

## Review Focus

- Placar fora da faixa ou malformado (`p=9-9`, `p=abc`, `p=-1-0`) → 400 sem gravar → `test_bet_rejects_malformed_score` (Task 2).
- Palpite exatamente no apito (`now == kickoff`) → fechado → `test_bet_at_kickoff_is_closed` (Task 1).
- Resultado de jogo nunca registrado (PUT result de `match_id` desconhecido) → 404, sem criar jogo → `test_result_for_unknown_match_is_404` (Task 3).
- Flamengo visitante: cartela e pontos sempre na ótica Fla x adversário → `test_away_match_scores_from_flamengo_side` (Task 6).
- Apelido com HTML (`<b>x</b>`) escapado na página e no e-mail → `test_nickname_is_escaped` (Task 2).
